# 리디자인 시안 — 레퍼런스와 변경 사항

| 번호 | 내용 | 가져온 것 |
|---|---|---|

| 007 | July Insights 다크 카드, 일지 목록, 하단 탭 | 가장 중요한 것 하나를 검정 면으로, 영문 대문자 머리말 |

| 013 | Queue: 아주 굵은 표제, 카드 없는 목록, 회색 알약 버튼 | 카드 없는 논문 목록, 회색 알약 「모두 보기」 |

| 001~004, 008, 010, 014, 015, 019 | 금융·숙소·온보딩·캘린더 등 | 분위기만 참고(흑백 비중, 큰 여백). 화면 구조는 맞지 않아 쓰지 않음 |

**공통 특징:** 흑백 중심(색은 하나 이하), 아주 굵은 표제, 알약 모양 버튼·칩, 카드 남발 대신 여백과 가는 선, 읽기 화면에는 세리프 본문, 조작은 화면 아래에 떠 있는 알약.

레퍼런스끼리 달랐던 점과 고른 방향:
- 다크 테마(015, 007 바깥) ↔ 밝은 테마(012, 013) → 앱은 밝은 테마, 검정은 강조 면으로만.
- 떠 있는 둥근 탭바(013) ↔ 바닥에 붙은 탭바(007, 020) → 바닥에 붙은 탭바. 라벨을 키우라는 피드백을 반영하기 쉽고, 리더의 떠 있는 조절 알약과 역할이 구분된다.

## 2. 기존 UI 대비 주요 변경점

| 영역 | 기존 | 시안 |
|---|---|---|
| 전체 톤 | 흰 카드 위주, 모든 묶음이 같은 카드 | 바탕 위 목록 + 묶음만 카드 + 가장 중요한 것 하나만 다크 카드 |
| 표제 | 26pt 제목 | 34pt Display(탭 화면), 홈 헤드라인도 같은 체계 |
| 홈 추천 논문 | 흰 카드 | 다크 카드 |
| 홈 논문 목록 | 카드 안 행 | 카드 없이 바탕 위 행 |
| 탐색 칸 | 밑줄 탭(논문 \| 공식 소식 \| 모델) | 알약 세그먼트 |
| 공식 소식 발표/업데이트 | 세그먼트 | 밑줄 탭(위 세그먼트와 위계 구분) |
| 지난 논문 | 날짜 글자 행 | 큰 날짜 숫자 + 요일 |
| 모델 칸 | 1위도 같은 행 | 1위는 다크 카드(라이선스·좋아요·다운로드 3칸) |
| 상세 화면 탭바 | 상세로 들어가면 탭바가 사라짐 | 논문·소식·모델 상세, 읽기 설정에서도 탭바 유지(들어온 탭 표시). 리더·시트만 숨김 |
| 논문 상세 | 상단 바에 가·공유·북마크, 하단에 주 버튼 | 상단은 뒤로·가만, 주 버튼·공유·북마크는 탭바 바로 위에 붙은 버튼 줄(A안) |
| 핵심 내용 근거 | 글자 링크 「원문 근거 · …›」 | 인용 아이콘이 있는 회색 알약 |
| 리더 모드 전환 | 상단 바 세그먼트 | 하단 떠 있는 검정 세그먼트 + 「가」(레퍼런스 009) |
| 용어 하이라이트 | 회색 | 노란색(레퍼런스 011). 원문 쪽은 옅은 회색 |
| 근거 시트 | 회색 상자 | 왼쪽 검정 막대 인용 상자 |
| 보관함 | 행 + 북마크 | 행 위에 종류·출처 머리말, 저장된 북마크는 검정 원 |
| 설정 | 글자만 있는 행 | 행마다 아이콘 칸(32pt) |
| 읽기 설정 | 세그먼트 2개 | 라디오 + 설명, 글자 크기 슬라이더 + 단계 글자 미리 보기 |

## 3. 기능·흐름 보존

**새로 넣거나 뺀 기능은 없다.** 화면마다 기존 데이터만 보여 준다.

| 기능 | 시안에서 |
|---|---|
| 홈: 오늘의 논문 3편, 연구소 소식, 바뀐 도구, 모델, 각 「더 보기」 | 그대로(01·02) |
| 새 글 점 | 소식 출처 줄 앞, 탐색 「공식 소식」, 설정 공지사항 행(탭바에는 없음) |
| 북마크(논문·소식·모델) | 모든 목록 행·카드·상세 |
| 공유 | 상세 화면(논문은 하단 버튼 줄, 소식·모델은 상단), 업데이트 카드 |
| 논문 상세: AI 요약, 핵심 내용 + 근거, 원문 출처·HF·발행일, 리더 진입 | 그대로(03) |
| 근거 시트 → 「초록 전체에서 보기」 | 그대로(04) |
| 리더: 함께·번역·원문, 글자 크기, 문장 번호, 용어 → 용어 시트 | 그대로, 위치만 하단으로(05·06) |
| 탐색: 오늘의 논문 + 주제 칩, 지난 논문(달별 접기, 지연·없음 표시) | 그대로(07) |
| 공식 소식: 발표/업데이트, 출처 칩, 짧은 원문 표시, AI 안내 | 그대로(08) |
| 소식 상세: AI 요약, 핵심 내용 + 근거, 관련 소식, 원문 열기 | 그대로(09) |
| 모델: 트렌딩 순위, 한 줄 설명, 라이선스·반응 / 상세의 한눈에·강점·점수·한계·안내 | 그대로(10·11) |
| 보관함: 종류·출처·저장일, 해제 → 되돌리기, 전체 비우기, 오프라인 안내 | 그대로(12) |
| 설정: 읽기 설정, 공지사항, AI 생성 안내, 데이터 출처, 처리방침, 문의, 앱 버전 | 그대로(13) |
| 읽기 설정: 초록 기본 보기, 글자 크기 4단계 + 미리 보기 | 그대로, 컨트롤 모양만 바뀜(14) |

검토하면서 고친 것:
1. 첫 시안의 보관함에 종류별 거르기 칩(전체·논문·공식 소식·모델)을 넣었다가 뺐다. 지금 앱에 없는 기능이다.
2. 한국어 머리말에 영문용 자간이 들어가 「멀 티 모 달」처럼 보여서 한국어는 자간 0으로 나눴다.
3. 다크 카드가 표제에 붙어 있던 간격(겹친 margin)을 고쳤다.
4. 근거 시트의 「밀어 내리면 닫혀요」 문구를 뺐다. 시트는 손잡이로 충분히 알 수 있다.
5. 소식 상세에서 「관련 소식」이 화면 아래로 잘려서 한 화면 안에 보이게 맞췄다. 탭바를 남긴 뒤로는 관련 소식 카드 끝이 탭바에 살짝 가리고, 스크롤하면 다 보인다.
6. 상세 화면에도 탭바를 남기기로 하면서(사용자 의견), 논문 상세의 떠 있던 하단 버튼을 탭바 위에 붙은 버튼 줄로 바꿨다. 버튼 높이를 54→50으로 줄여 아래쪽 조작 영역이 화면을 너무 차지하지 않게 했다.

## 4. 이번 시안에 없는 화면

공지사항 목록·시트, 데이터 출처, 개인정보 처리방침, 지난 날짜, 로딩·오류·빈 상태. 같은 토큰(카드·목록 행·시트·안내 문구)으로 그대로 만들 수 있어 주요 화면 위주로 그렸다.

## 5. 데이터와 파일

- 화면의 논문·소식·모델은 레포의 가상 데이터(`fixtures/`)다. 실제 글은 쓰지 않았다.
- 기존 프로젝트 파일은 바꾸지 않았다. 모든 결과물은 `design-preview/` 안에 있다.
