## 1. 콘셉트

**잉크와 종이.** 흰 종이 위 검정 잉크만으로 위계를 만드는 읽기 앱이다. 색은 새 글 점 하나뿐이고, 무게는 크기·굵기·면(다크 카드)으로 나눈다.

- 화면마다 **큰 표제 하나**(Display 34pt)로 어디에 있는지 바로 알게 한다(레퍼런스 013 「Queue」, 006 「Explore」).
- **가장 중요한 것 하나만 검정 면**(다크 카드)으로 띄운다. 홈은 오늘의 주요 논문, 모델 칸은 트렌딩 1위(레퍼런스 007, 016).
- 목록은 카드를 겹겹이 쌓지 않는다. 바탕 위 행 + 가는 구분선이 기본이고, 카드는 묶음 단위로만 쓴다(레퍼런스 013, 021).
- 읽는 화면은 글이 주인공이다. 조작은 화면 아래 떠 있는 검정 알약 하나로 모은다(레퍼런스 009, 005).

## 3. 타이포그래피

## 4. 레이아웃·간격

- 기준 기기 402×874pt, 상태바 54pt, 하단 안전 영역 34pt.
- 간격 4/8 리듬: 2·4·6·8·12·16·20·24·32·40. 묶음 사이 36, 묶음 제목 아래 12.
- 좌우 여백: 글 20, 카드 16(카드 안쪽 20).
- 모서리: 카드 22, 다크 카드 26, 시트 30, 칩·버튼 999(알약), 머리글자 배지 10.
- 하단 탭바는 상세 화면에도 남긴다. 숨기는 곳은 초록 리더(글에 집중, 자체 조절 알약이 있음)와 시트뿐이다.
- 그림자는 쓰지 않는다. 예외는 세그먼트의 선택 알약(1px, 6%) 하나뿐이다.

## 7. 터치·접근성

- 누르는 영역 44pt 이상(목록 원형 버튼은 보이는 원 36, 누르는 영역 44), 이웃 버튼 사이 8pt 이상.
- 상태(선택·저장)는 색과 함께 모양으로도 보인다: 채움/외곽선, 굵기, 밑줄.
- 리더의 떠 있는 조절 알약 아래로 내용이 사라지기 전에 바탕색 페이드를 둔다(스크롤 내용이 버튼과 겹쳐 보이지 않게).

## 8. 움직임·진동 (마이크로인터랙션 1차)

조용한 읽기 앱이라 「눌렀다·저장됐다·넘어갔다」를 확인시키는 작은 반응만 둔다. 길이는 150~250ms, 사라질 때가 나타날 때보다 빠르게. iOS 「동작 줄이기」면 움직이지 않고 바로 바뀐다. 진동은 iOS 시스템 햅틱 설정을 따른다.

| 언제 | 움직임 | 진동 |
|---|---|---|
| 옆으로 밀어 다른 탭으로 | 민 방향에서 40pt 밀려 들어오며 흐림 40% → 100%, 220ms easeOutCubic | 선택 틱 |
| 탐색 안 칸 넘김 | PageView 미끄러짐 250ms | 선택 틱 |
| 탭바·세그먼트·밑줄 탭·라디오·글자 크기 단계 | 세그먼트 알약·밑줄이 옆으로 미끄러짐 200~220ms | 선택 틱(다른 칸일 때만) |
| 북마크 저장·해제 | 원이 1 → 0.85 → 1.12 → 1, 260ms | 가벼운 톡 |
| 보관함에서 빼기 | (행이 바로 빠지고 되돌리기 알림) | 조금 더 또렷한 톡 |
| 누름(모든 버튼·행) | 불투명도 0.85, 100ms | 없음 |

넣지 않은 것: 목록이 차례로 나타나는 효과, 튀는 화면 전환. 다음 후보: 카드 눌림 시 97%로 작아지기, 읽은 새 글 점이 작아지며 사라지기.


## 9. 통일 행 구조 (2026-10-29)

앱의 모든 목록 행은 한 가지 모양을 쓴다: **머리 줄 `[칩] 보조 글자 · 날짜 [새 글]` → 제목 → (한 줄 설명) → 오른쪽 북마크**. 칩만 내용에 따라 바뀐다(`RgRowHead`, `RgChip` — `lib/design/widgets/rg_row_head.dart`).

| 행 | 칩 | 보조 글자 |
|---|---|---|
| 논문(홈·탐색·지난 날짜) | 주제, 중립 fill | 날짜 · 저자 |
| 공식 소식 발표·홈 연구소 소식·관련 소식·소식 상세 머리 | 출처 이름, 회사 대표 색(`RgBrand`) | 분류 · 날짜 + 「새 글」 |
| 바뀐 도구(홈)·업데이트 카드 | 출처 이름, 회사 대표 색 | 버전·건수 · 날짜(공지는 「공지」) |
| 모델(탐색)·트렌딩 1위 다크 카드 | Hugging Face(노랑) | 라이선스 · 좋아요 · 다운로드 / 트렌딩 N위 |
| 보관함 | 대표 색이 있는 출처면 출처 칩, 아니면 종류(논문) | 종류 또는 출처 · 저장일 |

칩: 높이 24 알약, 12.5/600. 다크 카드 위는 흰 14%. 분류·날짜는 칩이 아니라 글자(검토안에서 칩 4개가 제목보다 먼저 보였다). 「새 글」은 작은 글자라 점보다 진한 `newText`(대비 4.5:1). 저장은 북마크(저장되면 검정 원).

## 10. 움직임 2차 (2026-10-29)

토큰 `RgMotion`(`lib/design/tokens.dart`): press 100ms · release 160ms · fast 150ms · base 220ms · 곡선 easeOutCubic · 눌림 98%. 「동작 줄이기」면 `RgMotion.of(context, d)`가 0을 준다.

| | 언제 | 움직임 |
|---|---|---|
| ① | 행·카드 누름(`RgPressable(row: true)`, 모든 `RgListRow`·다크 카드·업데이트 카드·대표 소식) | 98%로 작아지고 4% 어두워짐(100ms), 떼면 easeOutBack으로 돌아옴(160ms). 동작 줄이기면 어두워지기만 |
| ② | 북마크 저장 | 기존 톡(0.85 → 1.12 → 1, 260ms) + 원 바탕이 120ms 동안 검정으로 물듦 |
| ③ | 상세를 읽고 돌아옴 | 「새 글」이 0.6배로 작아지며 흐려지고(180ms) 자리가 메워짐 |
| ④ | 주제·출처 칩, 발표·업데이트 바꿈(`RgFilterSwitch`) | 칩 채움 150ms, 새 목록이 살짝 떠오르며 나타남(160ms), 높이는 220ms로 맞춤 |
| ⑤ | 보관함에서 빼기 | 행이 흐려지며 높이가 접히고(220ms) 그다음 지움 → 되돌리기 알림. 되돌리면 같은 자리에 펼쳐짐 |
| ⑥ | 세그먼트·밑줄·탐색 칸·탭 넘김 | 모두 base 220ms + easeOutCubic으로 통일 |

앞으로 기능을 고치거나 더할 때도 눌림·전환·진동을 같이 설계한다(150~260ms, 동작 줄이기 존중, 목록 차례 등장·튀는 전환은 넣지 않음).

## 11. 용어 설명 넓히기 · 모델 두 칸 (2026-10-29)

시안: `src/terms_models_preview.html` → `work/compare/terms_models_preview.png`.

- **용어 강조가 걸리는 곳**: 리더 문장, 논문 상세 AI 요약·핵심 내용 카드, 공식 소식 상세(요약·핵심 내용), 모델 상세(강점·한계). 홈 카드는 눌러서 들어가는 카드라 강조하지 않는다.
- **카드 안 규칙**: 카드 하나에서 용어당 처음 1번만(`cardHighlights`). 모양은 리더와 같다(노랑 `highlight`, 모서리 4, 여백 3/1).
- **한글에서 찾는 순서**: 이 논문 번역문의 표기(`term_ko_span`) → 사전 대응어 → 번역문에 남은 영문(SFT·VLM) → 사전 별칭. 영문은 낱말 단위(RAG ≠ RAGAS), 한글은 앞이 한글이 아닐 때만.
- **공식 소식·모델**: 공용 용어 사전(`list_terms`, 승인 + 논문에 쓰인 용어). 시트는 「뜻」 + 「용어 사전 · 논문 N편에서 쓰임」.
- **모델 「트렌딩 | 새로 나옴」**: 밑줄 탭(`RgUnderlineTabs`) + `RgFilterSwitch`. 새로 나옴 = 최근 14일 안에 공개, 트렌딩 순 10개, 다크 카드 없이 목록, 머리 줄에 「N일 전 공개 · 하는 일」.
- **변형 묶음**: 양자화판과 같은 회사 형제 모델은 원래 모델 아래 「변형 N개 · 꼬리 이름 ›」. 누르면 펼침.
- **「새로 진입」**: 이 기기에서 처음 보는 모델에 붙는다(처음 받은 목록은 기준이라 붙지 않음). 열면 「새 글」처럼 사라진다.

움직임·진동:

| 무엇 | 값 |
|---|---|
| 용어 누름 | 노랑 → 진한 노랑 100ms(`press`), 시트 닫히면 160ms(`release`), 선택 틱 |
| 두 칸 전환 | 밑줄 220ms 미끄러짐, 목록 160ms 페이드 + 8pt 떠오름, 선택 틱 |
| 변형 펼침 | 높이 220ms(`base`), 셰브론 90° 회전 220ms, 선택 틱 |
| 「새로 진입」 사라짐 | 180ms 페이드 + 축소(`RgNewLabel`) |
