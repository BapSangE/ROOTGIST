# ROOTGIST 이용 안내

ROOTGIST(이하 「앱」)는 AI 논문과 연구소 소식을 한국어로 쉽게 읽도록 돕는 무료 앱입니다. 앱을 쓰기 전에 아래 내용을 확인해 주세요. App Store에서 받은 경우 Apple의 표준 사용권 계약(EULA)도 함께 적용됩니다.

## 1. AI가 만든 내용

- 논문 요약·핵심 내용·번역, 공식 소식 요약, 용어 설명, 모델 강점 정리는 AI가 원문을 보고 만든 것입니다. 틀리거나 빠진 내용이 있을 수 있습니다.
- 정확한 내용은 각 항목의 원문 링크(arXiv, Hugging Face, 각 회사 블로그 등)에서 확인해 주세요. 원문과 앱의 내용이 다르면 원문이 우선입니다.
- 모델 점수와 강점은 제작사가 직접 밝힌 내용이며, 앱이 따로 검증한 결과가 아닙니다.
- 앱의 내용은 정보 제공을 위한 것이며, 연구·투자·구매 등 중요한 결정의 유일한 근거로 쓰지 말아 주세요.

## 2. 콘텐츠의 권리

- 논문·글의 저작권은 각 저자와 회사에 있습니다. 앱은 글 전체를 옮기지 않고 제목·짧은 요약과 원문 링크만 보여 줍니다.
- 표시된 회사·제품 이름은 각 소유자의 상표입니다. 앱은 이 회사들과 제휴하거나 후원받지 않습니다.
- 권리자가 요청하면 해당 내용을 바로 내립니다. 문의 메일로 알려 주세요.

## 3. 서비스의 변경과 중단

- 앱은 무료로 제공되며, 기능과 내용은 미리 알리고 바뀌거나 중단될 수 있습니다. 중요한 변경은 앱의 공지사항으로 알립니다.
- 원문 사이트나 데이터 제공처의 사정으로 일부 내용이 늦게 올라오거나 빠질 수 있습니다.

## 4. 개인정보

개인정보 처리는 「개인정보 처리방침」을 따릅니다. 앱은 회원가입이 없고, 사용 분석은 직접 켠 경우에만 수집합니다.
