# ROOTGIST 개인정보 처리방침

개정 초안: 선택적 사용 분석을 포함하는 다음 빌드용입니다. 현재 배포·심사 중인 빌드에는 적용되지 않습니다. 공개 시행일·처리 지역·보관 기간은 배포 전에 확정합니다.

ROOTGIST(이하 「앱」)는 회원가입 없이 이용할 수 있습니다. 사용 분석은 선택 사항이며 기본으로 꺼져 있습니다. 이 방침은 앱이 어떤 정보를 다루는지 설명합니다.

## 1. 수집하는 개인정보

- 앱은 이름·연락처·정밀 위치·사진·광고 식별자를 분석에 사용하지 않습니다. 회원가입·로그인이 없고 이메일 등으로 이용자를 식별하지 않습니다.
- 설정에서 「사용 분석 데이터 수집」을 직접 켠 경우에만 PostHog를 사용합니다. 끄면 추가 이벤트 수집이 중단되며 앱의 다른 기능은 계속 사용할 수 있습니다.
- 수집 항목: 임의로 생성된 앱 설치 식별자, 이벤트 시각, 정해진 화면·기능 이름, 논문·소식 등 공개 콘텐츠 ID, 카테고리 코드, 북마크 추가·삭제 여부, 용어 팝업 표시 여부, 앱이 활성화되어 리더가 보이는 시간, 개발·TestFlight 구분입니다.
- SDK는 앱 버전·빌드, 운영체제·기기 종류 등 기술 정보를 이벤트에 붙일 수 있습니다. 설치 식별자는 같은 설치의 재방문을 집계하는 데 쓰며 다른 서비스 계정·이메일과 연결하지 않습니다.
- 논문 본문·초록·번역문·요약·용어 설명·제목·검색어·이메일·원문 URL은 분석 이벤트에 넣지 않습니다. 세션 리플레이, 화면 녹화, 자동 오류·로그 수집은 사용하지 않습니다.
- 이용 목적은 기능 사용성·재방문율·읽기 경험 개선이며 광고·광고 추적에 사용하지 않습니다.

## 2. 기기 안에만 저장되는 정보

다음 원본과 설정은 기기 안에 저장됩니다. 앱을 삭제하면 함께 지워집니다. 분석을 허용한 경우 북마크 동작과 공개 콘텐츠 ID 등 1장의 제한된 사용 이벤트만 별도로 전송합니다.

- 북마크 원본: 저장한 논문·공식 소식·모델의 ID·제목·출처·종류·저장한 시각
- 읽기 설정: 초록 기본 보기 방식, 글자 크기, 화면 바탕
- 분석 수집 허용 여부: 기본 거부이며 설정에서 변경할 수 있습니다
- 새 글 표시: 열어 본 공지사항·공식 소식의 ID와, 새 글을 표시하기 시작한 기준 시각(처음 실행한 때)
- 최근에 받은 논문·공식 소식·모델 데이터: 인터넷 연결이 없을 때 다시 보여 주기 위한 저장본

## 3. 서버와의 통신

- 앱은 논문 요약·번역과 공식 소식·모델 정보를 받기 위해 데이터베이스 서비스(Supabase)에 읽기 요청을 보냅니다. 이 요청에는 이용자의 개인정보나 북마크가 담기지 않습니다.
- 인터넷 통신의 특성상 접속한 IP 주소와 요청 시각이 서비스 제공자의 접속 기록에 남을 수 있습니다. 앱 운영자는 이 기록으로 이용자를 식별하거나 다른 목적에 쓰지 않습니다.

## 4. 외부 링크, 공유, 문의

- 원문(arXiv, Hugging Face, 각 연구소 블로그 등) 링크는 기기의 브라우저로 열립니다. 그 사이트에서는 해당 사이트의 개인정보 처리방침이 적용됩니다.
- 공유 기능은 기기의 공유 화면을 이용하며, 앱은 공유한 내용을 저장하지 않습니다.
- 「문의하기」는 기기의 메일 앱을 엽니다. 보내 주신 메일 주소와 내용은 답변에만 쓰고, 문의 처리가 끝나면 지체 없이 삭제하며, 제3자에게 제공하지 않습니다.

## 5. 제3자 제공과 처리 위탁

- 사용 분석을 허용한 경우 분석 처리를 위해 PostHog로 이벤트를 전송합니다. 해당 프로젝트의 처리 지역은 빌드에 설정된 PostHog Host에 따릅니다. 실제 처리 지역, 처리자 정보, 보관 기간 및 국외 이전 고지 사항은 다음 빌드 공개 전에 확정해 이 방침에 기재합니다.
- 인터넷 통신 과정에서 PostHog가 IP 주소와 접속 시각을 처리할 수 있습니다. 앱 이벤트에는 IP를 직접 넣지 않고 위치 추론을 비활성화하도록 요청합니다.
- 수집을 꺼도 이미 서버에 도착한 데이터가 자동 삭제되는 것은 아닙니다. 삭제 문의는 아래 연락처로 할 수 있습니다. 로그인 정보가 없어 특정 설치의 기록을 찾는 데 제한이 있을 수 있습니다.
