# ROOTGIST 개인정보 처리방침

개정 초안: 선택적 사용 분석을 포함하는 다음 빌드용입니다. 현재 배포·심사 중인 빌드에는 적용되지 않습니다. 시행일은 그 빌드를 배포하는 날로 이 문서에 적습니다. 사용 분석 서비스(PostHog)의 프로젝트를 만들면 처리 지역을 확인해 5장에 고쳐 적습니다.

ROOTGIST(이하 「앱」)는 회원가입 없이 이용할 수 있습니다. 사용 분석은 선택 사항이며 기본으로 꺼져 있습니다. 이 방침은 개인정보 보호법 제30조에 따라 앱이 어떤 정보를 왜, 얼마나 오래 다루는지 설명합니다.

## 1. 처리 목적과 처리하는 항목

- 앱은 이름·연락처·정밀 위치·사진·광고 식별자를 수집하지 않습니다. 회원가입·로그인이 없고 이메일 등으로 이용자를 식별하지 않습니다.
- 사용 분석(선택): 설정에서 「사용 분석 데이터 수집」을 직접 켠 경우에만 PostHog로 보냅니다. 끄면 추가 수집이 바로 멈추며 앱의 다른 기능은 그대로 쓸 수 있습니다.
- 사용 분석 항목: 임의로 만든 앱 설치 식별자, 이벤트 시각, 정해진 화면·기능 이름, 논문·소식 등 공개 콘텐츠 ID, 카테고리 코드, 북마크 추가·삭제 여부, 용어 설명 표시 여부, 리더가 화면에 보인 시간, 개발·TestFlight 구분입니다. SDK가 앱 버전·빌드, 운영체제·기기 종류 같은 기술 정보를 함께 붙일 수 있습니다.
- 사용 분석 목적: 기능 사용성·재방문율·읽기 경험 개선. 광고나 광고 추적, 개인별 맞춤 마케팅에 쓰지 않습니다.
- 사용 분석에 넣지 않는 것: 논문 본문·초록·번역문·요약·용어 설명·제목·검색어·이메일·원문 주소. 세션 리플레이, 화면 녹화, 자동 오류·로그 수집도 쓰지 않습니다.
- 문의 메일: 「문의하기」로 보내 주신 메일 주소와 내용은 답변에만 씁니다.

## 2. 기기 안에만 저장되는 정보

다음 정보는 기기 안에만 저장되고 앱 운영자에게 전송되지 않습니다. 앱을 삭제하면 함께 지워집니다.

- 북마크: 저장한 논문·공식 소식·모델의 ID·제목·출처·종류·저장한 시각
- 읽기 설정: 초록 기본 보기 방식, 글자 크기, 화면 바탕
- 사용 분석 허용 여부: 기본 거부이며 설정에서 바꿀 수 있습니다
- 새 글 표시: 열어 본 공지사항·공식 소식·모델의 ID와, 새 글을 표시하기 시작한 기준 시각
- 최근에 받은 논문·공식 소식·모델 데이터: 인터넷 연결이 없을 때 다시 보여 주기 위한 저장본

## 3. 처리·보유 기간과 파기

- 사용 분석 데이터: 수집한 날부터 1년간 보관한 뒤 PostHog에서 자동으로 지웁니다. 그 전에 지워 달라고 요청하면(7장) 확인한 뒤 지체 없이 지웁니다.
- 문의 메일: 답변을 마치면 지체 없이 지웁니다. 같은 문의가 이어지는 경우에도 마지막 답변으로부터 1년을 넘겨 보관하지 않습니다.
- 기기 안의 정보: 앱을 삭제하면 지워집니다. 북마크는 보관함의 「전체 비우기」로도 지울 수 있습니다.
- 파기 방법: 전자 파일은 다시 읽을 수 없는 방법으로 지웁니다. 종이로 출력해 보관하는 개인정보는 없습니다.

## 4. 서버와의 통신

- 앱은 논문 요약·번역과 공식 소식·모델 정보를 받기 위해 데이터베이스 서비스(Supabase)에 읽기 요청을 보냅니다. 이 요청에는 이용자의 개인정보나 북마크가 담기지 않습니다.
- 인터넷 통신의 특성상 접속한 IP 주소와 요청 시각이 서비스 제공자의 접속 기록에 남을 수 있습니다. 앱 운영자는 이 기록으로 이용자를 식별하거나 다른 목적에 쓰지 않습니다.
- 원문(arXiv, Hugging Face, 각 연구소 블로그 등) 링크는 기기의 브라우저로 열리며, 그 사이트의 개인정보 처리방침이 적용됩니다. 공유 기능은 기기의 공유 화면을 쓰며 앱은 공유한 내용을 저장하지 않습니다.

## 5. 제3자 제공, 처리 위탁, 국외 이전

- 앱은 이용자의 개인정보를 제3자에게 제공하지 않습니다.
- 처리 위탁: 사용 분석을 켠 경우에만 PostHog, Inc.가 분석 데이터를 처리합니다(위탁 업무: 앱 사용 분석 데이터의 저장·집계).
- 국외 이전: PostHog 서버는 국외에 있습니다. 이전 항목은 1장의 사용 분석 항목, 이전 시기는 사용 분석을 켠 뒤 앱을 쓸 때마다 인터넷으로 전송, 보유 기간은 3장과 같습니다. 처리 지역은 유럽연합(EU) 리전으로 만들 예정이며, 프로젝트를 만든 뒤 국가와 리전을 이 장에 확정해 적습니다.
- 이전을 원하지 않으면 사용 분석을 켜지 않거나 언제든 끄면 됩니다. 앱의 다른 기능은 그대로 쓸 수 있습니다.
- PostHog가 IP 주소와 접속 시각을 처리할 수 있습니다. 앱 이벤트에는 IP를 직접 넣지 않고, 위치 추론을 끄도록 요청합니다.

## 6. 만 14세 미만 아동

- 앱은 아동을 대상으로 하지 않으며 나이를 묻지 않습니다.
- 만 14세 미만이라면 사용 분석을 켜지 말아 주세요. 만 14세 미만 아동의 개인정보를 처리하려면 법정대리인의 동의가 필요합니다. 만 14세 미만 아동이 사용 분석을 켠 사실을 알게 되면 해당 데이터를 지웁니다.

## 7. 이용자의 권리와 행사 방법

- 이용자는 언제든 사용 분석을 끄는 것으로 처리 정지를 요구할 수 있습니다(설정 → 사용 분석).
- 설정 → 사용 분석 → 「분석 데이터 삭제 요청」을 누르면 수집이 꺼지고 앱 설치 식별자가 새로 바뀝니다. 동시에 이전 식별자를 적은 삭제 요청 메일이 준비됩니다. 이 메일을 보내 주시면 그 식별자로 PostHog에 쌓인 기록을 찾아 지우고 결과를 알려 드립니다.
- 열람·정정·삭제·처리 정지 요구는 아래 메일로도 할 수 있습니다. 로그인 정보가 없어 앱 설치 식별자 없이는 특정 설치의 기록을 찾기 어려울 수 있습니다.
- 법정대리인이나 위임을 받은 사람도 요구할 수 있습니다. 요구를 받으면 10일 안에 처리 결과를 알려 드립니다.

## 8. 안전성 확보 조치

- 관리적 조치: 개인정보를 다루는 사람을 운영자 1명으로 한정합니다.
- 기술적 조치: 모든 통신은 HTTPS로 암호화합니다. 분석 서비스와 데이터베이스의 관리 권한은 운영자 계정만 가지며, 관리용 키는 앱에 넣지 않고 서버에만 둡니다. 앱에서 데이터베이스에는 공개 읽기 요청만 보냅니다.
- 앱 이벤트에는 본문·검색어·이메일처럼 내용을 담은 값이 들어가지 않도록 코드에서 막습니다.

## 9. 개인정보 자동 수집 장치

- 앱은 쿠키를 쓰지 않습니다.
- 사용 분석을 켠 경우에만 PostHog SDK가 기기에 임의의 설치 식별자를 저장해 같은 설치의 재방문을 집계합니다. 사용 분석을 끄면 전송이 멈추고, 「분석 데이터 삭제 요청」을 누르면 식별자가 새로 바뀝니다.
