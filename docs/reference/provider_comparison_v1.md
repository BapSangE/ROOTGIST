## 1. 왜 바꿔야 하나

NVIDIA API Trial Terms of Service:
- **1.2조:** 제한된 시험 목적으로만 제공하며, API 서비스나 생성 결과물을 운영(production)에 쓰지 않는 조건이다.
- **4.2조:** 1.2조의 허용 범위를 빼면 생성 결과물을 다른 사람에게 배포하거나 제공할 수 없다.

개발과 내부 테스트는 시험 목적에 해당한다. **외부 사람에게 결과를 보여 주는 시점(지인 대상 베타 포함)부터는 운영으로 보고, 그 전에 제공처를 바꾼다.**

## 3. 예상 비용 (A1 결정: 하루 상위 10편)

평가에서 측정한 토큰을 쓴다. 입력은 1회 약 3,400토큰이다. 출력은 deepseek 평균 약 8,000토큰, glm 평균 약 18,000토큰(v0.5.2 확인 실행 기준)이다. 추론 토큰도 출력으로 청구된다고 가정한다(두 회사 모두 "입력·출력 토큰 합계로 청구"라고만 적혀 있음).

| 경우 | 1회 비용 | 하루 | 한 달(평일 22일) |
|---|---|---|---|
| deepseek, 논문당 1회 호출 | 약 $0.0053 | 약 $0.05 | **약 $1.2** |
| deepseek, 논문당 2회(두 모드) | 약 $0.0106 | 약 $0.11 | 약 $2.3 |
| glm(예비), 1회 | 약 $0.0095 | 실패 시에만 사용 | 무시할 수준 |
| 참고: 하루 전체(평균 72편) deepseek 1회씩 | — | 약 $0.38 | 약 $8.4 |

다음 날 목록 재조회(A7 보충)는 HF API만 쓰므로 모델 비용이 없다.

## 4. 약관 비교 (공식 문서, 2026-10-17 확인)

| 항목 | DeepSeek Open Platform Terms (2026-04-29 시행) | Z.ai Terms of Use + API Additional Terms (2026-04-14 갱신) |
|---|---|---|
| 생성 결과물 권리 | 4.2조: 결과물의 권리를 이용자에게 양도. 파생 제품 개발 등 넓은 용도 허용 | IV.4조: 이용자가 결과물의 권리를 보유. 다른 이용자의 결과물과 비슷할 수 있음 |
| 최종 사용자에게 제공 | 허용. 단 **AI 생성물임을 명확히 알려야 함**, 오류 가능성과 참고용임을 안내(8.1조) | 허용. 단 **AI 생성물을 눈에 띄게 표시**(III.5(d)), **Z.ai 모델 사용 사실을 밝혀야 함**(API 추가 약관 1(d)), 최종 사용자와 권리·의무 약정(1(b)) |

| 데이터 위치·준거법 | 저장 위치 명시 없음. 준거법 중화인민공화국법, 관할 항저우(10.1, 10.2조) | 관할 밖에서 처리·저장될 수 있음(IV.3(a)(ii)). 세부는 데이터 처리 부속서 |
| 개인정보 | 최종 사용자에게 개인정보 처리 규칙 고지(3.3조) | 데이터 처리 부속서 적용 |

**우리 상황에서의 의미**
- 모델에 보내는 내용은 **공개된 논문 초록**이고 사용자 개인정보는 보내지 않는다. 그래서 학습 이용·데이터 위치 차이의 영향은 작다.
- 두 곳 모두 앱에 **"AI가 생성한 요약·번역입니다. 오류가 있을 수 있습니다"** 같은 표시가 필요하다. 예비 모델(glm)을 쓰는 경우를 고려하면 **사용 모델 제공처 표시**도 넣는다.
- 준거법이 중국법(DeepSeek)이라는 점은 분쟁 시 불리할 수 있다. 다만 사용 금액이 월 몇 달러 수준이라 실제 위험은 작다.

## 5. 다른 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| OpenRouter 등 중개 서비스 | 한 계정으로 여러 제공처, 장애 시 자동 전환 | 요청마다 다른 업체 서버로 갈 수 있어 설정·양자화가 달라짐. 중개 서비스 약관 + 각 업체 약관 확인 필요 |
| 다른 호스팅 업체(예: Deep Infra) | 미국 등 다른 지역 서버 | 업체별 약관 확인 필요. 요금은 비슷한 수준으로 보도됨(공식 확인 안 함) |
| NVIDIA AI Enterprise | 지금 쓰는 엔드포인트와 같은 방식 | 기업용 유료 라이선스. 월 몇 달러 규모의 우리 사용량에는 과함 |
| 직접 호스팅 | 데이터가 밖으로 나가지 않음 | GPU 비용·운영 부담이 큼 |

## 6. 제안

1. **운영 기본: DeepSeek 공식 API(`deepseek-flash`), 예비: Z.ai 공식 API(GLM-5.3-Flash).** 평가한 모델과 같은 모델을 원 개발사에서 직접 쓴다. 비용은 월 몇 달러 수준이다.
2. **전환할 때 할 일**
   - 각 공식 API로 확인 실행을 한 번 한다(예: P05·P13·P17 × 2모드). 제공처가 바뀌면 설정이 달라질 수 있다. 예를 들어 DeepSeek 공식 API는 "생각 모드"가 기본값이고, JSON 강제 옵션이 NVIDIA에서와 다르게 동작할 수 있다.
   - 앱에 AI 생성 표시와 제공처 표시를 넣는다.
   - 약관과 요금을 다시 확인한다.
3. **그 전까지:** NVIDIA API는 개발과 내부 테스트에만 쓰고, 결과를 외부에 보여 주지 않는다.
