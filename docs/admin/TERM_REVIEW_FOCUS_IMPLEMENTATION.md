- 문맥은 EN/KO를 나란히 비교한다. 회색 밑줄은 선택된 검토 표기의 첫 위치를 찾기 위한 것이며, 아래 노란 미리보기는 기존 `projectPaperForPreview`의 실제 앱 규칙을 그대로 사용한다.
- 표기 일치 수와 **선택 문장에서 해당 용어가 실제로 강조되는 수**를 구분한다. 실제 앱의 승인/표시 설정, 금지 정의, 중복·겹침·문장 순서도 반영한다.

- 1200px 미만 목록 펼침, 960px 미만 사전 펼침. native dialog로 배경 클릭/초점·단축키를 막고 Escape/닫기/초점 복귀를 제공한다.

- 강조 미리보기는 항목/논문/적용 위치별 메모리에만 남는다. 이동 시 유지/버리기/계속 검토를 선택한다. 새로고침/이탈 시 변경 경고를 제공한다. DB 저장·localStorage 지속 저장이 아니다.

## 시안과 실제 R0의 차이

시안의 가상 승인 동작은 운영 코드에 옮기지 않았다. **사전 표기/정의/별칭/메모는 읽기 전용**, 임시 저장/수정 필요/승인은 비활성이다. 별도의 활성화된 ‘다음 항목’으로 이동한다. M5 워커 보호·M6 저장 연결이 준비되기 전까지 화면만으로 쓰기 권한을 열지 않는다.

기존 API 경로/서버 키/권한/읽기 전송기/private-no-store/쓰기423은 변경하지 않았다. Flutter·워커·DB·migration·배포 환경변수도 이 작업에서 수정하지 않았다. 동시에 진행 중인 사용자의 다른 작업은 포함하지 않는다.
