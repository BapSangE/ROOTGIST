## 보완한 설명

### ablation · 절제

모델의 특성이나 구성 요소를 제거한 뒤 성능 변화를 비교해 각 요소의 중요도를 확인하는 방법. 예: 이미지 분류 모델에서 색상 정보를 빼고 정확도가 얼마나 달라지는지 비교하는 실험.

### active learning · 능동적 학습

모델이 학습에 도움이 될 데이터를 골라 라벨을 요청하거나 확보하는 학습 방법. 예: 모델이 판단하기 어려워하는 사진을 골라 사람에게 정답을 붙여 달라고 요청하는 경우.

### attention · Attention,

입력 요소마다 중요도에 따른 가중치를 주어 현재 처리에 필요한 정보를 모으는 신경망의 계산 방식. 예: 번역할 단어와 관련이 큰 입력 단어의 정보를 더 높은 비중으로 반영하는 계산.

### autoencoder · autoencoder

입력을 내부 표현으로 압축하는 인코더와 이를 원래 입력에 가깝게 복원하는 디코더를 함께 학습하는 모델. 예: 사진을 작은 수치 벡터로 압축한 뒤 원래 사진에 가깝게 복원하도록 학습하는 모델.

### data augmentation · 데이터 증강

기존 데이터에 회전, 자르기, 표현 변경 등을 적용해 학습 사례의 수와 다양성을 늘리는 방법. 예: 고양이 사진을 좌우로 뒤집거나 밝기를 바꾸어 학습용 사진의 다양성을 늘리는 경우.

### distillation · 증류

큰 교사 모델의 출력이나 내부 표현을 작은 학생 모델이 따라 배우도록 하는 학습 방법. 예: 큰 언어 모델이 여러 답에 부여한 확률을 작은 모델이 따라 배우도록 학습하는 경우.

### dropout regularization · 드롭아웃 정규화

학습 단계마다 일부 뉴런의 출력을 무작위로 제외해 특정 뉴런에 대한 의존과 과적합을 줄이는 방법. 예: 학습할 때마다 일부 뉴런의 출력을 사용하지 않아 다른 뉴런도 예측에 기여하도록 만드는 경우.

### embedding space · 임베딩 공간

데이터를 벡터로 표현해 의미나 관계의 유사성을 위치와 거리로 나타내는 공간. 예: 의미가 비슷한 두 문장을 가까운 벡터 위치에 두어 검색에서 함께 찾을 수 있게 하는 공간.

### embedding vector · 임베딩 벡터

단어나 이미지 등 데이터의 특징과 관계를 수치 좌표로 나타낸 벡터. 예: 문장의 의미를 숫자 목록으로 바꾸어 다른 문장과의 유사도를 비교하는 경우.

### epsilon greedy policy · epsilon greedy 정책

일정 확률로 무작위 행동을 하고 나머지 경우에는 현재 가치가 가장 높은 행동을 고르는 강화학습 정책. 예: 대부분은 현재 보상이 높을 것으로 예상하는 행동을 고르고, 일부는 무작위로 시도하는 규칙.

### few-shot prompting · 퓨샷 프롬프팅

소수의 입력과 원하는 출력 예시를 프롬프트에 넣어 모델의 응답 방식을 유도하는 방법. 예: 긍정·부정으로 분류한 문장 몇 개를 먼저 보여 준 뒤 새 문장의 감정을 분류하도록 요청하는 방식.

### gradient descent · 경사하강법

손실 함수의 기울기와 반대 방향으로 매개변수를 조금씩 갱신해 손실을 줄이는 최적화 방법. 예: 집값 예측 오차가 줄어드는 방향으로 면적에 곱하는 가중치를 조금씩 바꾸는 과정.

### grounding · 그라운딩

신뢰할 수 있는 자료나 관측 결과를 근거로 모델의 답변을 구성하는 과정. 예: 제품 설명서를 근거로 기능을 안내해, 모델이 확인되지 않은 기능을 지어내는 일을 줄이는 경우.

### L1 regularization · L1 정규화

가중치 절댓값의 합에 불이익을 주어 일부 가중치가 0이 되도록 유도하는 정규화 방법. 예: 예측에 덜 필요한 입력 특징의 가중치를 0으로 만들어 사용하는 특징 수를 줄이는 경우.

### L2 regularization · L2 정규화

가중치 제곱의 합에 불이익을 주어 지나치게 큰 가중치를 억제하는 정규화 방법. 예: 한 입력 특징의 가중치만 지나치게 커지지 않도록 큰 가중치에 더 큰 벌점을 주는 경우.

### learning rate · 학습률

경사하강법에서 기울기에 따라 매개변수를 얼마나 크게 갱신할지 조절하는 값. 예: 같은 기울기를 계산했더라도 학습률이 작으면 가중치를 더 조금 바꾸는 갱신.

### LoRA · LoRA

기존 가중치를 고정하고 작은 저차원 행렬만 학습해 모델을 미세 조정하는 방법. 예: 기본 언어 모델의 가중치는 고정하고 작은 추가 행렬만 학습해 고객 문의 응답에 맞추는 경우.

### loss function · 손실 함수

모델의 예측과 정답 또는 학습 목표의 차이를 수치로 계산하는 함수. 예: 실제 집값과 예측 집값의 차이를 제곱해 예측 오차를 계산하는 함수.

### overfitting · 과적합

모델이 학습 데이터의 세부 패턴과 잡음까지 지나치게 익혀 새로운 데이터에서 성능이 떨어지는 현상. 예: 학습에 사용한 고양이 사진은 잘 맞히지만 새로운 고양이 사진에서는 자주 틀리는 경우.

### policy · 정책

강화 학습에서 현재 상태를 바탕으로 행동이나 행동의 확률분포를 정하는 규칙. 예: 로봇이 장애물의 위치를 보고 왼쪽과 오른쪽 중 어느 방향으로 움직일지 정하는 규칙.

### precision · precision

모델이 양성으로 예측한 사례 중 실제로 양성인 사례의 비율. 예: 스팸이라고 예측한 메일 10개 중 실제 스팸이 8개일 때 80%인 정밀도.

### quantization · 양자화

모델의 가중치나 활성값을 더 적은 비트나 제한된 값으로 표현해 저장 공간과 연산 부담을 줄이는 기법. 예: 32비트로 저장하던 모델 가중치를 8비트로 표현해 저장 공간을 줄이는 경우.

### regularization · 정규화

모델의 복잡성이나 매개변수에 제약을 주어 학습 데이터에 대한 과적합을 줄이는 방법. 예: 학습 오차만 줄이는 대신 너무 큰 가중치에도 벌점을 주어 복잡한 규칙에 대한 의존을 줄이는 방법.

### reinforcement learning (RL) · 강화 학습 (RL)

에이전트가 환경과 상호작용하며 얻은 보상을 바탕으로 미래 누적 보상을 높이는 행동 정책을 학습하는 방법. 예: 로봇이 물체를 잘 집으면 보상을 받고, 시행착오를 거치며 성공할 행동을 배우는 경우.

### Reinforcement Learning from Human Feedback (RLHF) · 인간 피드백 기반 강화 학습(RLHF)

사람이 평가한 응답의 선호나 품질을 보상 신호에 반영해 모델을 개선하는 강화 학습 방법. 예: 사람이 더 선호한 답변을 보상 모델 학습에 활용하고, 그 점수를 이용해 언어 모델의 응답을 개선하는 경우.

### retrieval-augmented generation (RAG) · 검색 증강 생성(RAG)

외부 문서나 지식 저장소에서 관련 정보를 검색한 뒤 이를 입력 맥락에 넣어 답변을 생성하는 방법. 예: 사내 규정 문서를 검색한 뒤 찾은 내용을 참고해 휴가 규정에 답하는 경우.

### self-attention (also called self-attention layer) · 셀프 어텐션 (셀프 어텐션 계층이라고도 함)

같은 입력 시퀀스 안의 요소 사이에 관련도를 계산하고 그 비중에 따라 정보를 결합해 각 요소의 표현을 만드는 방식. 예: 문장 속 대명사의 표현을 만들 때 같은 문장의 관련 인물 정보를 함께 참고하는 계산.

### semi-supervised learning · 준지도 학습

정답이 붙은 데이터와 정답이 없는 데이터를 함께 활용하여 모델을 학습하는 방법. 예: 정답이 붙은 사진 100장과 정답이 없는 사진 수천 장을 함께 활용해 이미지 분류기를 학습하는 경우.

### transfer learning · 전이 학습

다른 작업이나 데이터에서 학습한 지식을 새로운 작업의 학습에 활용하는 방법. 예: 다양한 이미지로 미리 학습한 모델을 꽃 사진 분류에 맞게 추가 학습하는 경우.

### underfitting · 과소적합

모델이 데이터의 중요한 패턴을 충분히 학습하지 못해 학습 데이터에서도 예측 성능이 낮은 현상. 예: 곡선 형태의 관계를 직선 하나로만 표현해 학습 데이터의 값조차 잘 맞히지 못하는 경우.

### word embedding · 단어 임베딩

단어를 의미나 사용 맥락의 관계를 담은 밀집 벡터로 나타내는 표현 방법. 예: 비슷한 문맥에서 쓰이는 단어들을 비슷한 벡터로 나타내어 단어 사이의 관계를 비교하는 방식.

### zero-shot prompting · 제로샷 프롬프팅

원하는 응답의 예시를 제시하지 않고 지시나 질문만으로 과제를 수행하도록 하는 프롬프트 작성 방법. 예: 분류 예시 없이 문장과 긍정·부정을 판별하라는 지시만 제공하는 경우.

### autoregressive models · 자기회귀 모델

앞서 주어진 내용으로 다음 항목을 예측하고, 그 결과를 이어 사용해 순서대로 출력을 만드는 모델. 예: 문장의 앞부분을 보고 다음 단어 조각을 예측한 뒤, 그 결과를 붙여 다음 조각을 이어 만드는 경우.

### self-attention · 셀프 어텐션

한 입력의 각 요소가 같은 입력 안의 다른 요소 중 어느 부분을 참고할지 계산하여 표현을 만드는 방식. 예: 문장 속 대명사의 표현을 만들 때 같은 문장의 관련 인물 정보를 함께 참고하는 계산.

### frozen decoder · 동결된 디코더

추가 학습 중에도 매개변수를 갱신하지 않고 기존 가중치를 유지하는 디코더. 예: 시각 정보를 연결하는 모듈만 추가 학습하고, 디코더의 가중치는 그대로 두는 구성.

### low-rank adapter (LoRA) · LoRA

기존 모델의 가중치는 유지하면서 작은 저랭크 행렬을 추가해 학습할 매개변수 수를 줄이는 미세 조정 모듈. 예: 기본 모델은 고정한 채 작은 행렬만 학습해 특정 분야의 문장 생성에 맞추는 경우.

### KV cache · KV 캐시

언어 모델이 앞선 토큰에서 계산한 키와 값 정보를 저장해, 다음 토큰을 생성할 때 같은 계산을 반복하지 않도록 하는 임시 저장소. 예: 답변의 다음 토큰을 생성할 때 앞선 토큰의 키·값 계산을 저장소에서 가져와 재사용하는 경우.

### retrieval-augmented methods · 검색 증강 방법

외부 자료에서 질문과 관련된 정보를 찾아 모델의 입력에 더함으로써 답변 생성을 돕는 방법. 예: 질문과 관련된 문서를 먼저 찾고, 그 문서를 모델에 함께 전달해 답변을 만드는 경우.

### autoregressive video model · 자기회귀 비디오 모델

앞서 나온 프레임이나 영상 조각을 바탕으로 다음 장면을 차례로 생성하는 영상 모델. 예: 앞선 몇 프레임으로 다음 영상 조각을 만든 뒤, 생성한 장면을 이어 다음 조각을 만드는 경우.

### autoregressive world models · 자기회귀 월드 모델

앞선 상황을 바탕으로 다음 상황을 예측하고, 그 결과를 다시 활용해 이후 상황을 차례로 예측하는 AI 모델. 예: 로봇이 이동한 뒤의 상황을 예측하고, 예측한 상황을 바탕으로 그다음 상황을 이어 예측하는 경우.

### behavioral cloning · 행동 복제

상황과 전문가의 행동을 짝지은 데이터를 이용해, 비슷한 상황에서 전문가처럼 행동하도록 AI를 학습시키는 방법. 예: 사람이 컵을 집는 시범을 보고 로봇이 비슷한 상황에서 같은 동작을 배우는 경우.

### teacher forcing · 교사 강제

순서가 있는 데이터를 생성하는 모델을 학습할 때, 앞 단계의 모델 예측 대신 실제 정답을 다음 예측의 입력으로 제공하는 방식. 예: 정답이 ‘나는 밥을 먹는다’일 때, 모델이 앞 단어를 틀려도 정답인 ‘나는 밥을’을 주고 다음 단어를 예측하게 하는 학습.

### action-conditioned · 행동 조건부

어떤 행동을 수행하는지를 입력으로 함께 받아, 그 행동 이후의 상태나 관찰 결과를 예측하는 방식. 예: 로그인 버튼을 누른다는 행동을 입력하면, 그 뒤 어떤 화면이 나타날지 예측하는 경우.

### credit assignment · 크레딧 할당

여러 행동으로 얻은 최종 결과에서 각 행동의 기여도를 판단하고 학습 신호를 배분하는 문제. 예: 로봇이 컵을 떨어뜨렸을 때 잡는 힘과 이동 속도 중 어떤 행동 선택이 실패에 영향을 주었는지 따져 보는 문제.

### attention mask · 어텐션 마스크

모델이 어텐션 계산에서 어떤 위치를 참고할 수 있는지 지정하는 값의 배열. 예: 다음 단어를 예측하는 모델이 뒤에 나올 정답 단어를 미리 참고하지 못하도록 가리는 설정.

### recall · 재현율

실제 양성인 사례 중 모델이 양성으로 올바르게 찾아낸 사례의 비율. 예: 실제 스팸 메일 10개 중 8개를 찾아냈을 때 80%인 재현율.

### self-supervised learning · 자기지도 학습

사람이 별도로 정답을 붙이지 않은 데이터에서 예측 목표를 만들어 모델을 학습하는 방법. 예: 문장 일부를 가리고 원래 단어를 맞히게 하여, 별도 정답 라벨 없이 텍스트에서 학습하는 경우.

### variational autoencoder (VAE) · 변분 오토인코더

입력을 확률분포로 압축하고 그 분포에서 얻은 값으로 데이터를 복원하며, 새로운 데이터도 생성할 수 있도록 학습하는 오토인코더 계열. 예: 얼굴 사진에서 배운 확률분포의 값을 뽑아, 학습 사진과 다른 새 얼굴 이미지를 생성하는 경우.
