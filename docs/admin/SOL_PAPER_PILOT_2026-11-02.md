# ROOTGIST 논문 3편 — 현재 대화에서 직접 작성한 초안과 기존 결과 비교

작성: 2026-11-02 KST

## 이 실험으로 확인한 것

등록된 논문 초록 3편을 읽고, 기존 요약·번역·용어 결과를 조회하기 전에 새 결과 JSON을 작성하고 해시로 고정했다. 22개 원문 문장 ID를 유지하고 용어 16개를 선택했다. 실제 앱·DB·배치 설정은 변경하지 않았다.

**독립된 GPT-6.1 Sol medium API 호출 실험이 아니라 현재 대화에서 직접 작성한 시연**이다. 이 대화의 작업 맥락과 편집 지시가 영향을 주며, API 비용·토큰 수·응답 시간은 측정하지 않았다. 모델·추론 설정은 사용자가 지칭한 현재 대화 환경이며 별도 API에서 검증한 설정이 아니다. high 설정은 실행하지 않았다.

기존 결과는 DB에 저장된 deepseek-flash / p2-prompt-v0.6 생성본이다. 새 초안은 현재 워커 기본 p2-prompt-v0.6.2를 참조했다. 표기·분류 지시가 다르고, 기존 glossary 설명은 관리자 및 앞선 AI 편집이 반영된 현재 값이므로 **통제된 모델 A/B 평가나 순수 모델 우열 판정에 사용할 수 없다.**

## 재현 가능한 확인

- 논문: TAO(2610.37230), PDRVLA(2610.37381), SpecSlot(2610.40647).
- 입력: DB 영문 제목·초록·저장된 Axx 문장, 현재 워커 방식으로 추린 승인 선호 표기.
- 외부 본문 검색 없이 제공된 초록으로 요약·번역·근거 연결 작성. 일반 용어 정의에는 모델의 기존 지식 사용.
- 기존 결과 조회 전 세 JSON 저장 및 SHA-256 고정: draft-seal.json.
- 기존 worker.validate.check 실행: 3/3 통과.
- 추가 검사: 용어 표기가 연결한 각 문장의 원문에 실제 있는지 확인, 오류 0개.
- 전체 번역: 22개, 용어: 16개, 워커의 영문 출현·정의 기반 highlight 조건 통과: 16/16. 실제 앱의 한국어 강조·사전 연결은 미검증.
- 형식·위치 검사 통과는 의미·번역의 완벽함을 보장하지 않음. 아래 평가는 작성자의 자체 검토이며 독립된 사람 평가가 아님.
- 운영 preferred_terms 규칙 예외 1건: TAO의 언어 모델 토큰에 '비전 토큰'이라는 선호 표기가 전달돼 그대로 쓰지 않고 '토큰'으로 유지했으며 limitations에 명시. 이 입력 충돌은 모델을 바꾸는 것과 별도로 점검해야 함.
- 요청 ID·API 토큰 사용량·API 비용·API 지연 시간은 모두 미측정. 대화 작업 소요 시간을 API 지연으로 환산하지 않음.

## 직접 비교한 결과

### TAO — 풀어 쓴 설명의 이점

기존 A04: '시간 인식 감쇠가 적용된 노드별 캐시 크레딧'

새 초안 A04: '시간이 지날수록 줄어드는 노드별 캐시 재사용 이점'

새 표현이 점수·시간 감소의 역할을 읽기 쉽게 풀어 쓴다는 장점. 다만 '수용 용량 제약' 등은 여전히 전문적인 표현이고, 새 용어 목록이 논문의 핵심인 tool-return readiness와 cache credit를 별도 해설로 선택하지 않은 아쉬움. 기존 용어 선정에 장점이 있으므로 새 결과를 전면 우위로 보지 않음.

최대 개선치 26.8%·36.3%·29.5%, 실험 설정 12개, 지표별 최상위 비교 기법 조건을 보존했다. 최대 수치가 동일한 조건에서 동시에 얻어진 것인지 초록만으로 단정하지 않았다.

### PDRVLA — 번역체 완화와 용어 선택의 상충

기존 A03: '물리 토큰을 추출해 온라인 영상 생성 없이 행동 생성을 조건화한다'

새 초안 A03: '실행 중에 영상을 생성하지 않고도 이 정보를 조건으로 행동을 생성한다'

'온라인'이 인터넷 연결처럼 읽힐 위험과 '조건화'의 추상성을 줄이는 쪽으로 작성했다. 네 벤치마크의 성공률은 모두 번역에 보존하고 요약에서는 범위를 사용했다. 시뮬레이션 결과를 실제 로봇 성능으로 일반화하지 않았다.

다만 새 초안의 '비전 토큰'은 입력 사전의 표기를 따른 표현이며 원문의 physical tokens와 완전히 같은 전문 명칭은 아니다. 핵심 개념은 '물리적 변화를 담은 토큰'이라는 설명과 함께 검토할 필요가 있다. 초록의 human-to-robot synthesis를 '사람의 동작을 로봇 동작으로 합성'으로 푼 부분도 대상 데이터의 구체적 범위를 본문으로 확인하면 더 정확해질 수 있다. ECoT·subtask conditioning을 골랐던 기존 결과와 달리 새 초안은 제어 루프·구성 요소 제거 실험 같은 기본 개념을 골랐다는 한계가 있다.

### SpecSlot — 비교 조건과 수치 방향 보존

원문 A08의 FLOPs를 맞춘 비교는 ImageNet-256 문장에 있고 A09에서는 3.9% 적은 FLOPs를 보고한다. 기존 핵심 내용은 'FLOPs를 맞춘 대조군 대비 ... 3.9% 적은 FLOPs'를 함께 써 비교 조건을 혼동할 여지가 있다. 새 초안은 A09의 비교 조건만 사용했다.

또한 FID 2.84 개선은 2.84%가 아니라 지표 값 차이로 보존했다. JiT-B/16과의 FID 차이 0.69는 원문에 방향이 명시되지 않아 우열을 덧붙이지 않았다. 비용 감소 38.2%와 순전파 비용 감소 40.6%도 서로 다른 표현으로 유지했다. '공간 기준점', '국소 보정' 등은 여전히 입문 사용자에게 어려울 수 있어 추가 편집 여지가 있다.

## 판단

현재 대화에서 직접 작성하는 방식으로는 운영 스키마와 문장 연결을 지키면서 더 쉽게 풀어 쓴 초안을 만들 수 있었다. 용어 선정과 일부 해석에는 기존 결과가 나은 측면도 있어, 이 세 편으로 Sol의 일관된 우위나 작업당 비용 우위를 단정할 수 없다.

다음 통제 비교는 같은 입력·프롬프트·승인 사전 조건으로 DeepSeek와 Sol medium/high의 독립 API 호출을 실행하고, 사람 평가와 재시도 포함 비용을 기록하는 방식이 적절하다. 이번 작업에서는 유료 API 호출이나 운영 모델 교체를 하지 않았다.

## 결과물

- index.html: 세 편의 요약·핵심·Axx별 번역·용어를 기존 결과와 나란히 보는 읽기 전용 비교 화면
