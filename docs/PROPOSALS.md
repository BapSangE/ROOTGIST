## P8. 출처·신뢰 신호 확장 (HF Trending 포함)

- **배경**: 사용자 의견 「HF Daily Papers도 arXiv 기준이고, arXiv는 심사 전에 올리는 곳이라 신뢰성이 떨어진다. AAAI 같은 학회나 GitHub 별 많은 레포, Claude·GPT 공식 소식처럼 공부할 만한 곳이 더 있을까」, 「Hugging Face Trending은 매력적」.
- **짚어 둘 것**
  - arXiv는 심사 전 사전 공개 서버다. 다만 주요 학회 채택 논문도 대부분 arXiv에 같이 올라오므로 「arXiv = 미검증」이 아니라 「검증 여부를 아직 모름」에 가깝다.
  - HF Daily Papers의 순서는 커뮤니티 upvote다. 화제성 신호이지 품질 보증이 아니다(이미 데이터 출처 화면에 적혀 있다).
  - 그래서 **출처를 늘리기 전에 지금 논문에 신뢰 신호를 덧붙이는 것**이 작고 효과가 크다.

### HF Trending 확인 결과 (2026-10-26, 공개 API 직접 호출)

- `GET https://huggingface.co/api/models?sort=trendingScore` — 키 없이 바로 된다. `datasets`, `spaces`도 같은 모양. 항목마다 `trendingScore`, `likes`, `downloads`, `pipeline_tag`(과제 종류), `createdAt`, `tags`(`license:…`, `arxiv:…`)가 온다.
- 상위 10개 모델 중 **논문(`arxiv:` 태그)이 연결된 것은 3개**였다. Trending은 「논문」보다 「모델 출시」 소식에 가깝다.
- 라이선스는 apache-2.0·mit도 있지만 `other`(개별 조건)도 섞인다.
- 상위권에 성인·검열 해제(「Uncensored」) 계열 모델·Spaces가 섞여 있었다. **그대로 노출하면 안 되고 거르는 규칙이 필요하다**(이름·태그 차단 목록 + 사람 확인).
- 「Trending Papers」(huggingface.co/papers/trending)는 웹 페이지만 있고 공개 JSON API는 확인되지 않았다(`/api/papers/trending` 404). 쓰려면 페이지를 긁어야 해서 깨지기 쉽다. 지금 쓰는 `/api/daily_papers`는 그대로 된다.
