# 기획 제안 (iOS 실기기 QA에서 나온 것)

2026-10-25~26 iOS 실기기 QA([IOS_QA.md](IOS_QA.md)) 중 체크리스트 메모와 추가 의견에서 나온 기획·UX 제안을 모았다. 버그와 바로 고칠 수 있던 것은 이미 반영했고(맨 아래 「반영한 것」), 여기 남은 것은 **결정이 필요한 것**이다.

각 항목: 배경 → 지금 상태 → 제안(안이 여럿이면 추천 표시) → 바뀌는 곳 → 크기 → 정할 것.
크기는 S(하루 안), M(2~3일), L(1주 이상, 시안 필요) 기준의 어림이다.

## P7. 개인정보 처리방침·문의하기

- **배경**: 체크리스트 추가 메모 「내용 추가 필요」.
- **지금 상태**: S06 「정보」 그룹에 행은 있지만 `privacyPolicyUrl`·`contactEmail`이 `null`이라 눌리지 않는다(`lib/data/settings.dart`, HANDOFF 10장 G13).
- **제안**
  - 처리방침 문서를 정적 페이지로 둔다(예: GitHub Pages). 앱은 인앱 브라우저로 연다(지금 코드 그대로).
  - 내용은 사실대로 짧게: 계정·로그인 없음, 북마크·설정은 **기기 안에만** 저장, 서버(Supabase)는 논문 데이터 읽기만 하며 접속 기록(IP 등)이 서비스 제공자 로그에 남을 수 있음, 제3자 제공 없음, 문의처.
  - 문의는 전용 메일 주소 하나(`mailto:`). 개인 메일은 앱에 노출되므로 피한다.
- **바뀌는 곳**: `lib/data/settings.dart` 상수 2개, HANDOFF G13 확정. 문서 자체는 레포 밖(또는 `docs/` 별도 페이지).
- **크기**: S
- **정할 것**: 처리방침 호스팅 위치, 문의 메일 주소, 문서 문구 검토자.

## P2. 앱 이름·앱 ID·아이콘·스플래시

- **배경**: iOS-앱이름 메모 「아이콘과 앱 실행시 애니메이션은 미리 준비 필요」. 알려진 항목(IOS_QA 3.2 「앱 이름」).
- **지금 상태**
  - 홈 화면 이름: iOS `App Repo`, Android `app_repo`.
  - 앱 ID: iOS `com.example.appRepo`(QA 때만 로컬에서 `com.bapsange.rootgist`로 바꿔 씀, 커밋 안 함), Android `com.example.app_repo`.
  - 아이콘: Flutter 기본. 스플래시: 흰 화면.
  - 무료 Apple ID 서명은 7일마다 다시 설치해야 한다. 지인 베타(TestFlight)는 유료 Apple Developer 계정이 필요하다.
- **제안**
  - **앱 ID를 먼저 정한다**(예: `com.<조직>.rootgist`, iOS·Android 같게). 스토어에 올린 뒤에는 바꿀 수 없다.
  - 이름: 홈 화면 표시명 `ROOTGIST`(또는 한글 이름). 길이는 아이콘 아래 잘리지 않게 10자 안팎.
  - 아이콘: 불변 원칙(무채색)에 맞춰 오프화이트 바탕 + 검정 워드마크/모노그램. 시안 1장에서 `flutter_launcher_icons`로 두 플랫폼 크기를 만든다.
  - 스플래시: **정적**(배경 `bgApp` + 가운데 워드마크)을 권한다. 네이티브 스플래시는 애니메이션이 안 되고, Flutter 쪽에 애니메이션을 넣으면 그만큼 첫 화면이 늦어진다. 원하면 첫 프레임에서 워드마크가 짧게(200~300ms) 사라지는 정도만.
- **바뀌는 곳**: `ios/Runner/Info.plist`, `ios/Runner.xcodeproj`(번들 ID), `android/app/build.gradle*`·`AndroidManifest.xml`, 아이콘 에셋, `flutter_native_splash` 설정.
- **크기**: M(아이콘 시안 제외)
- **정할 것**: 앱 ID, 표시 이름, 아이콘 시안, 유료 개발자 계정 여부(지인 베타 시점).

## P1. 외부 링크 표시

- **배경**: iOS-외부링크 메모 「누르면 해당 논문으로 이동한다는 문구가 없어 사용자가 기능을 사용하기 어려울 듯」.
- **지금 상태**
  - S02 정보 카드의 「원문 출처 · arXiv · ID」 행은 누르면 Safari로 나가지만, 다른 정보 행(게시 조직·발행일)과 모양이 같아 눌리는 줄 모른다.
  - C03 안내문은 「상세 화면의 Hugging Face·arXiv 링크에서 확인」이라고 하는데 **HF 링크 행이 없다**(문구와 화면 불일치).
- **제안**
  - 누르는 행만 값 오른쪽에 외부 링크 아이콘(Lucide `arrow-up-right` 14, textTertiary)을 붙인다. 지금 아이콘 세트에 없으므로 같은 굵기(1.75)로 SVG 1개 추가.
  - 행 라벨을 「원문 보기」처럼 동작이 드러나게 바꾸는 안도 있다. 화면 읽기에는 「arXiv에서 원문 열기, 링크」.
  - HF 행을 추가할지(공유 문구에는 이미 HF 주소가 들어간다) C03 문구를 arXiv만으로 고칠지 정한다. **추천: HF 행 추가** — HF 페이지에 토론·코드 링크가 있어 쓸모가 있다.
- **바뀌는 곳**: `lib/features/paper/paper_screen.dart`(`_InfoRow`), `assets/icons/`, HANDOFF 7.2·7.8(C03 문구).
- **크기**: S
- **정할 것**: 아이콘만 / 라벨까지 바꿈, HF 행 추가 여부.

## P5. 추천 카드 「자세히 읽기」 버튼 정리

- **배경**: 체크리스트 추가 메모 「오늘의 주요 연구의 자세히 읽기 버튼 없이 새로 올라온 연구처럼 해당 박스를 클릭하면 자세히 화면으로 넘어가도록」.
- **지금 상태**: S01 추천 카드만 「자세히 읽기」 주 버튼 + 북마크 버튼이 있고, 아래 목록 행은 행 전체가 눌린다(HANDOFF 7.1 4행 ⑤).
- **제안**
  - 카드 전체를 누르면 S02로. 북마크는 카드 오른쪽 위로 옮겨 따로 눌리게 둔다(목록 행과 같은 방식, 화면 읽기에서도 별도 노드).
  - 버튼이 빠지면 눌린다는 신호가 약해지므로 카드 아래쪽에 「자세히 보기 ›」 보조 줄(caption textSecondary)을 두는 안도 있다. **추천: 보조 줄 없이 목록 행과 같은 눌림 피드백만** — 홈 전체가 「카드 = 누르면 들어감」으로 통일된다.
  - 검정 채움은 「주 버튼·선택된 필터·저장된 북마크에만」(불변 원칙)이라, 버튼이 빠지면 홈에서 검정 면이 줄어 더 차분해진다.
- **바뀌는 곳**: `lib/features/home/home_screen.dart`(`_FeaturedCard`), HANDOFF 7.1, VoiceOver 확인(Q03-홈 「카드는 주제 → 제목 → 날짜·저자 한 덩어리」).
- **크기**: S
- **정할 것**: 북마크 위치, 보조 줄 여부. 시안 1장 수정.

## P6. 사용 가이드·공지사항

- **배경**: 체크리스트 추가 메모 「처음 앱에 접속하면 가이드가 뜨고, 다시 보지 않기 버튼을 누르고 x를 누르면 공지사항에서 볼 수 있도록」.
- **지금 상태**: 첫 실행 안내 없음. 공지사항 화면 없음. S06 「안내」 그룹에 AI 생성 안내·데이터 출처만 있다.
- **제안**
  - **가이드**: 첫 실행에 바텀시트(RgBottomSheet) 한 장, 2~3쪽 넘김. ① 매일 상위 10편을 한국어로 ② 핵심 내용의 「원문 근거」로 초록 문장 확인 ③ 리더의 「함께」 보기와 용어 하이라이트. 일러스트 없이 글 + 기존 아이콘만(불변 원칙). 「다시 보지 않기」 체크 + 닫기.
  - 다시 보기: S06 「안내」 그룹에 「사용 가이드」 행 추가.
  - **공지사항**: 가이드와 분리한다. 가이드는 앱에 고정된 내용, 공지는 바뀌는 내용이라 Supabase 테이블(`notices`: 제목·본문·게시일, RLS 읽기 전용) + 읽기 RPC 1개가 맞다. S06에 「공지사항」 행 → 목록 화면. 공지가 없으면 행을 숨긴다.
  - 팝업 대신 홈 맨 위 닫을 수 있는 안내 카드로 가이드를 보여 주는 가벼운 안도 있다. **추천: 바텀시트** — 홈 레이아웃(헤드라인·추천 카드)을 건드리지 않는다.
- **바뀌는 곳**: 새 시트·화면, 로컬 저장 키 1개(HANDOFF 9.4, 예: `onboarding.dismissed`), S06 행 1~2개, (공지) DB 마이그레이션·RPC·Repository, HANDOFF 7.8·새 절.
- **크기**: M(가이드 S + 공지 M)
- **정할 것**: 가이드 문구·쪽 수, 공지를 MVP에 넣을지(외부 공개 전/후), 공지 작성 방법(Supabase 대시보드 직접 입력으로 충분한지).

  - 설정에 「화면 모드: 시스템 / 밝게 / 어둡게」(기본 시스템).
  - Q04(색 대비) 재검증, 시안 PNG 다크판 필요.
- **바뀌는 곳**: `lib/design/tokens.dart`·`theme.dart` 전체, 하드코딩된 색이 있는 위젯, S06 행 1개, HANDOFF 5.1.
