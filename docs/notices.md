# 공지사항

## AI가 만든 내용과 사용한 모델

2026.10.27

ROOTGIST의 요약, 핵심 내용, 번역, 용어 설명은 AI가 만들어요.

- 논문: 초록만 근거로 한국어 요약, 핵심 내용, 문장별 번역, 용어 설명을 만들어요. 핵심 내용은 초록 안에서 근거 문장을 찾을 수 있는 것만 보여 드려요.
- 공식 소식: 연구소 블로그 원문의 문단을 근거로 제목 번역, 요약, 핵심 내용을 만들고, 릴리스 노트는 핵심 변경 사항만 정리해요. 글 전체를 옮기지는 않아요.
- 사용 모델: DeepSeek 공식 API의 DeepSeek V4.1 Flash를 써요. 응답이 없거나 형식이 맞지 않으면 같은 모델로 다시 만들어요.
- AI에 보내는 것은 논문 초록, 공개된 블로그 글처럼 누구나 볼 수 있는 자료뿐이에요. 앱을 쓰는 분의 정보는 보내지 않아요.

AI가 만든 내용에는 오류가 있을 수 있어요. 중요한 내용은 각 화면의 원문 링크에서 확인해 주세요.

## 새 논문은 언제 올라오나요

2026.10.27

- 매일 한국 시간 새벽 4시쯤 전날 Hugging Face Daily Papers에서 upvote가 많은 상위 10편을 모아 정리해요. 정리가 끝나기 전에는 홈에 「모으는 중」이라고 나와요.
- arXiv는 주말에 새 논문을 발표하지 않아서 일요일·월요일 홈에는 새 논문이 없어요. 그날은 가장 최근 논문을 대신 보여 드려요.
- 순서는 Hugging Face 이용자들의 반응이고, ROOTGIST가 논문을 평가한 결과가 아니에요.

## 탐색에 「공식 소식」을 더했어요

2026.10.27

- 탐색 탭을 옆으로 밀면 Anthropic, OpenAI, Google DeepMind, Google Research, Hugging Face, Meta, NVIDIA의 공식 블로그 소식을 볼 수 있어요. Hugging Face 블로그에 NVIDIA·IBM·Microsoft 같은 회사 계정이 쓴 글도 그 회사 소식으로 보여 드려요.
- 「업데이트」에서는 Claude Code·Anthropic·OpenAI·xAI SDK 릴리스, Claude API 변경 사항, OpenAI 개발자 커뮤니티 공지를 모아 보여 드려요.
- 「화제」에서는 Hacker News에서 개발자들이 많이 본 AI 글과 GitHub의 새 AI 도구를 보여 드려요. 홈 브리핑에도 「개발자 화제」로 올라와요.
- 핵심 내용의 「근거」를 누르면 원문의 해당 문단으로 바로 열려요.
