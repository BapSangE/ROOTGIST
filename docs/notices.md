# 공지사항

## 탐색이 「논문 · 소식 · 도구」로 바뀌었어요

2026.11.12

- 논문: 오늘의 논문 10편과 지난 날짜의 논문을 분야별로 볼 수 있어요.
- 소식 › 발표: Anthropic, OpenAI, Google DeepMind, Meta, NVIDIA 같은 회사의 공식 블로그 소식이에요. 핵심 내용의 「근거」를 누르면 원문의 해당 문단이 열려요.
- 소식 › 업데이트: Claude Code·Anthropic·OpenAI·xAI SDK 릴리스, Claude API 변경 사항, OpenAI 개발자 커뮤니티 공지를 모아요.
- 소식 › 커뮤니티: Hacker News에서 많이 본 AI 글과 AI 회사·관계자의 X 글이에요. X 글은 30분마다 받아 한국어 번역과 원문을 함께 보여 드려요.
- 도구: Hugging Face 트렌딩 모델과 새 모델, GitHub에서 별을 많이 모은 새 AI 저장소(24시간·7일·30일)를 볼 수 있어요.
- 사용량 초기화나 무료 개방 같은 소식이 X에 올라오면 홈 맨 위 「혜택·한도 소식」에 바로 보여요.
- 설정 › 읽기 설정의 글자 크기가 소식, X 글, 공지 본문에도 적용돼요.

## AI가 만든 내용과 사용한 모델

2026.10.27

ROOTGIST의 요약, 핵심 내용, 번역, 용어 설명은 AI가 만들어요.

- 논문: 초록만 근거로 한국어 요약, 핵심 내용, 문장별 번역, 용어 설명을 만들어요. 핵심 내용은 초록 안에서 근거 문장을 찾을 수 있는 것만 보여 드려요.
- 공식 소식: 연구소 블로그 원문의 문단을 근거로 제목 번역, 요약, 핵심 내용을 만들고, 릴리스 노트는 핵심 변경 사항만 정리해요. 글 전체를 옮기지는 않아요.
- X 글: 공개 게시물을 요약하지 않고 그대로 한국어로 옮겨요. 번역 아래에 원문을 늘 함께 보여 드려요.
- 모델·저장소: Hugging Face 모델 카드와 GitHub README에 적힌 설명을 바탕으로 정리해요.
- 사용 모델: DeepSeek 공식 API의 DeepSeek V4.1 Flash를 써요. 응답이 없거나 형식이 맞지 않으면 같은 모델로 다시 만들어요.
- AI에 보내는 것은 논문 초록, 공개된 블로그 글과 X 게시물처럼 누구나 볼 수 있는 자료뿐이에요. 앱을 쓰는 분의 정보는 보내지 않아요.

AI가 만든 내용에는 오류가 있을 수 있어요. 중요한 내용은 각 화면의 원문 링크에서 확인해 주세요.

## 새 논문은 언제 올라오나요

2026.10.27

- 매일 아침 6시쯤(한국 시간) 전날 Hugging Face Daily Papers에서 upvote가 많은 상위 10편을 정리해 올려요. 정리가 끝나기 전에는 홈에 「모으는 중」이라고 나와요.
- arXiv는 주말에 새 논문을 발표하지 않아서 일요일·월요일 홈에는 새 논문이 없어요. 그날은 가장 최근 논문을 대신 보여 드려요.
- 순서는 Hugging Face 이용자들의 반응이고, ROOTGIST가 논문을 평가한 결과가 아니에요.
