# iOS 실기기 QA (맥북 + 아이폰, 무료 Apple ID)

M6의 「iPhone 실기기」 몫. Android는 에뮬레이터(Pixel 8, Android 17)로 Q01~Q13을 마쳤고(커밋 1d50fe8, a08d395), 여기서는 같은 체크리스트(HANDOFF 12장)를 아이폰에서 다시 보고 iOS에서만 다를 수 있는 곳을 더 본다.

## 1. 준비 (처음 한 번)

1. 맥에 설치: Xcode(App Store), Xcode 첫 실행 후 추가 구성 요소 설치, 그다음 터미널에서
   ```bash
   xcode-select --install
   ```
   ```bash
   brew install cocoapods
   ```
   Flutter 3.47.x(이 레포와 같은 버전). 설치 후 `flutter doctor`에서 Xcode·CocoaPods 항목이 초록이면 된다.
2. 레포 받기
   ```bash
   git clone https://github.com/BapSangE/ROOTGIST.git
   ```
3. Supabase 공개 키 파일: 레포 루트에 `.env.app.json`을 만든다. `.env.*`는 `.gitignore`에 있어 커밋되지 않는다. 키 값은 Windows PC에서 빌드할 때 쓰던 것과 같다(채팅에 붙이지 말 것).
   ```json
   { "SUPABASE_URL": "https://<프로젝트>.supabase.co", "SUPABASE_ANON_KEY": "<publishable 키>" }
   ```
   이 파일이 없으면 앱은 fixture(가짜 데이터)로 뜬다.
4. Xcode 서명
   - `open ios/Runner.xcworkspace` → 왼쪽 Runner → Signing & Capabilities
   - Team: 「Add an Account…」로 본인 Apple ID 추가 후 「(Personal Team)」 선택
   - **Bundle Identifier**: 정식 앱 ID `com.bapsange.rootgist`가 이미 들어 있다(iOS·Android 같음). 바꾸지 않는다.
   - Team을 고르면 Xcode가 `DEVELOPMENT_TEAM`(개인 Team ID)을 `project.pbxproj`에 써 넣는다. 사람마다 다른 값이라 **이 줄은 커밋하지 않는다**. Xcode가 함께 바꾸는 `objectVersion`·`Main.storyboard` 형식 변경도 커밋하지 않는다.
5. 아이폰
   - USB로 연결 → 「이 컴퓨터를 신뢰」
   - 설정 → 개인정보 보호 및 보안 → **개발자 모드** 켜기(재시작됨)
   - 첫 설치 후 앱이 안 열리면: 설정 → 일반 → VPN 및 기기 관리 → 개발자 앱(본인 Apple ID) → 신뢰

## 2. 설치

```bash
flutter pub get
```
```bash
flutter devices
```
```bash
flutter run --release --dart-define-from-file=.env.app.json -d <아이폰 기기 ID>
```

- QA는 `--release`로 한다. debug 빌드는 iOS에서 맥과 연결이 끊기면 홈 화면에서 다시 열리지 않는다.
- 무료 Apple ID 서명은 **7일** 뒤 만료된다. 앱이 안 열리면 같은 명령으로 다시 설치하면 된다(북마크 등 저장값은 유지).
- 첫 빌드는 `pod install` 때문에 몇 분 걸린다. CocoaPods 오류가 나면 `cd ios && pod repo update && cd ..` 후 다시.

### 3.3 VoiceOver (Q03)

- 켜기/끄기 단축: 설정 → 손쉬운 사용 → 손쉬운 사용 단축키 → VoiceOver. 이후 **측면 버튼 세 번**으로 켜고 끈다.
- 조작: 한 손가락 오른쪽/왼쪽 쓸기 = 다음/이전 항목, 두 번 탭 = 누르기, 두 손가락 위로 쓸기 = 처음부터 끝까지 읽기.
- 볼 것
  - 홈: 날짜와 「새 논문 N편이 올라왔어요」가 한 문장으로, 카드는 주제 → 제목 → 날짜·저자 순서로 한 덩어리로 읽힘
  - 북마크 버튼: 저장 전 「북마크에 저장」, 저장 후 「저장됨, 북마크 해제」로 상태가 바뀌어 읽힘
  - 상세: 근거 링크가 「원문 근거 · 초록 N번째 문장, 버튼」
  - 리더: 하이라이트된 용어가 「용어 설명: …, 버튼」으로 읽히고 두 번 탭하면 시트가 열림
  - 하단 탭: 지금 탭이 「선택됨」으로 읽힘
  - 읽는 중 이상한 기호(빈 칸 끊김, 특수 문자 이름)가 끼지 않음

## 5. 문제를 찾으면

- 문제가 있으면 화면 캡처(측면 버튼 + 볼륨 업)와 함께 「ID · 화면 · 무엇이 어떻게」로 적어 주면 고친다.
- 캡처에 실데이터(초록·번역)가 보이므로 레포에 올리지 않는다(HANDOFF 0.1).
- 끝나면 아이폰의 더 큰 텍스트·VoiceOver 설정을 원래대로 돌린다.
